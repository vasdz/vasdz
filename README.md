## 🛡️ About Me

I'm a Computer Security student at RTU MIREA with practical experience in security research, systems programming, and cybersecurity competitions.

My main interests are penetration testing, infrastructure security, vulnerability research, and reverse engineering. I enjoy understanding how systems work internally, investigating potential weaknesses, and developing tools to explore and improve system security.

- 🔎 **Security Research:** vulnerability analysis, security mechanisms, attack surfaces, and access control.
- 🐧 **Linux & Networking:** Linux internals, TCP/IP, sockets, routing, and virtual network interfaces.
- 🐳 **Container Security:** Docker experience and actively deepening my knowledge of Kubernetes security.
- 🔬 **Reverse Engineering:** binary analysis, debugging, and fuzzing.
- 🔐 **Cryptography:** regular participation in international cryptography competitions, including NSUCRYPTO.
- 🏆 **CTF:** Crypto, Reverse Engineering, Binary Exploitation, and Web.

I have professional experience in information security research and security architecture assessment, including technical analysis and preparation of security recommendations.

A custom VPN service built around a client-server architecture.

- TUN/TAP virtual interfaces for packet handling and encapsulation.
- Linux routing configuration and interaction with the operating system's network stack.

### [MySyslog](https://github.com/vasdz/mysyslog)

An extensible system logging library.

- Low-level memory and buffer management.

A remote file-copy utility.

- Network communication and file transfer.
